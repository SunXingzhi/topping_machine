v0.2 修订导读（相对 v0.1 的变更）

本版吸收 v0.1 评审意见，与 README.md v0.1 工程基线全面对齐。主要变更：

  1. 作业模式（D2 裁决）：人工推行 + 红外遥控触发逐株作业；删除自走巡行、接近、停稳状态，无需停车/静止判定；P1 预留拉车动力。
  2. 双相机（D5 裁决）：顶部深度相机（可调俯角转台 + 角度传感器，俯角 30°–60°）负责定位；侧装普通 RGB 相机负责花期观察与数据集采集，不进切割解算链；不做全株建模。
  3. 电机选型（D3 裁决）：切割主轴 = 无刷直流电机（电调 + 电流反馈）；XYZ 位置轴 = 步进电机（建议闭环）；刀盘倾角固定。
  4. 下位机（D6 裁决）：STM32F407，负责脉冲发生、主轴调速/电流采样、相机俯角读取、红外解码与硬件安全；UART+CRC16 协议。
  5. 数据集方案：公开示例数据集（预训练）+ 自建烟草花期数据集；台架阶段可用 3D 打印红球等替代目标先行打通全链路。
  6. 维护规程：响应 README §11，随本版发布（见 7.9 FR-K4）。
  7. 其余：状态机/FR/演示/工程结构/指标全面对齐 README；保留 §3 评审过程记录并新增裁决汇总表。

剩余待定：D7 斜角值、D8 打顶长度 H（按目标烟种确定）、D9 垄距/株距/株高实测（门架净高 165 cm 评审定值需与株高复核）、D10 指标冻结、D11 电池定量化、D12 相机具体型号（以会议纪要为准）、D13 软件框架。

1 背景与目标

1.1 问题与证据

打顶是烤烟关键农艺环节：现蕾意味着植株由营养生长转入生殖生长，须摘除花序及顶部一段茎叶（打顶长度 H），使养分集中供给剩余叶片，否则花果消耗养分导致显著减产；打顶同时须配合抑芽（控制腋芽）。〔来源：doc/topping_and_sucker_control_id160_2019.pdf〕

我国烟田目前仍以人工打顶为主，效率低、劳动强度大，且质量受熟练度影响，易出现打顶不及时、不均匀。〔来源：doc/适宜机器打顶作业的烟草种类调研.pdf〕国外机型（如意大利 Spapperi JS-120）打顶高度固定、方式粗放，存在过度打顶与漏打。〔来源：同上〕机械打顶可比人工节省约 67% 劳动投入；低损伤机械打顶是同类作物的明确技术方向。〔来源：doc/烟草打顶机器执行机构设计.pdf；损伤控制理念另参 doc/棉花打顶机设计.pdf〕

已有研究给出了可行的技术路径与量化参照：

  • 2011 年智能打顶抑芽机采用红外光电传感器对株高仿形（识别精度 98%），步进电机升降刀架打顶，并同步喷施抑芽剂（每株 ≥15 mL），样机作业速度 1.14–1.89 km/h，株距按 0.5 m 计，且配备了消毒装置。〔来源：doc/打顶+抑苗设计.pdf〕
  • 2025 年品种调研在 14 个主栽烤烟品种上给出了适宜机械打顶的株型特征（见 1.2），并定义了漏打率、准确率、上部叶损伤率及打顶效果综合评价公式（第 10 章引用）。〔来源：doc/适宜机器打顶作业的烟草种类调研.pdf〕
  • 打顶物（花序、顶叶、烟杈）需移出田间以防止病害传播；切口是病害传播通道。〔来源：doc/输送装置设计.pdf、doc/打顶+抑苗设计.pdf〕

1.4 目标（可观察结果表述）

  • 对株高差异在规格内的烟株逐株定位打顶，而非固定高度「一刀切」；切点偏差 ≤ δ_pos（初值 15 mm）。
  • 打顶后切口为符合固定倾角 θ 的斜面，上部叶无可目视损伤。
  • 单株自动流程 ≤ 5 s（推行对位时间另计，属人因环节）。
  • 异常（目标丢失、切割过流、急停）进入安全停机并给出可听/可见的原因提示，而非强行作业。
  • 作业结束自动产出可导出的单株级记录，支撑第 10 章指标核算。

3.3 ③ 定位机构选型——过程记录

工作空间测算依据：株高差异覆盖（Z 向约 35–45 cm）、烟花横向偏差（Y 向 ±15–20 cm）、沿推行向切割对准（X 向微调 10–20 cm）。XYZ 门式/悬臂滑台在包络形状、刚性、防尘、调试工时、成本上全面占优；Delta 仅速度占优而非本场景瓶颈。裁决：XYZ 悬臂滑台（X 沿推行向 ≥150 mm，Y ≥±200 mm，Z ≥400 mm），Delta 不再保留。

3.6 ⑥ 运动中打顶——过程记录

原设想「不影响车的运动」的行进中打顶：需要目标运动预测、时间同步、动态跟踪三者同时成立，叠加植株风摆，首版风险与工期不可行。

裁决：P0 采用人工推行 + 红外触发——比 v0.1 建议的「自走停切」更进一步简化：操作员推车即承担行走职能，触发即认为就位（无停车判定）；单株自动流程 ≤ 5 s。行进中打顶保留为 P1 能力演进方向。

4 范围与优先级

4.1 P0 —— 最小完整作业闭环

  1. 推行与驻停：门式跨垄车架（净高 165 cm 评审定值）、万向轮 ×4（≥2 带刹）、推行把手（集成急停/红外接收/状态灯）。
  2. 触发作业：上电一次性自检；红外「作业/停止」键；流程中防重复触发。
  3. 双相机感知：顶部深度相机（可调俯角转台+角度传感器）三态检测与 3D 定位；侧 RGB 观察/采集；不做全株建模。
  4. 定位与运动：XYZ 滑台（步进位置轴）、坐标系链解算、到位校验、软限位、可达性判断与对位提示。
  5. 打顶执行：无刷主轴刀盘、固定倾角斜切、主轴电流监测、退刀重试。
  6. 补偿链 C1–C6（外参/姿态/H 偏移/延迟复检/摆动窗口/到位校验）。
  7. 安全：硬件急停、护罩联动、上电安全态、上位机-下位机看门狗。
  8. 记录与提示：单株记录、批次汇总、蜂鸣/LED 结果语义、USB 导出。
  9. 标定与维护：手眼标定 SOP、轴回零、刀尖标定、开机自检、维护规程。

6 系统架构与坐标系

6.1 系统分层架构

职责划分：上位机负责非实时的感知、解算、状态机与记录；STM32 负责实时脉冲发生、主轴 ESC 与电流采样、相机俯角 β 读取、红外解码、急停回路监视与看门狗；急停为纯硬件回路。

通信协议（UART 115200 8N1，帧 [0xAA 0x55 | CMD | LEN | PAYLOAD | CRC16-CCITT]，RS485 为升级备选）：HOME_ALL / MOVE_ABS(目标位+速度+超时) / SPINDLE_ON·OFF / GET_STATUS / ABORT（软件中止=退刀停轴）/ SET_TOOL_OFFSET；遥测 20–50 Hz：轴位置 ×3、主轴电流/转速、俯角 β、红外键值、急停状态、电池电压、限位状态。

6.2 坐标系链（补偿解算唯一口径）

定义： C 顶部深度相机系（光心；OpenCV 惯例 Z 朝前 X 右 Y 下） S 侧 RGB 相机系 —— 仅观察/数据集，不进入切割解算链 V 车架基准系（门架顶部横梁标定基准孔；X 沿推行方向，Y 横向，Z 竖直向上） G 滑台基准系（三轴回零后的编码器零位；轴向与 V 平行，制造公差内） T 刀尖切割点系（刀盘几何中心下刀点；相对 G 的偏移由刀尖标定给出） 解算（每帧）： P_C = K⁻¹·[u,v]·depth // 内参 P_V = R_CV(β)·P_C + t_CV // C1 外参；R_CV = R_install(β)·R_res // β = 转台角度传感器实时读数（STM32 上报） Q_V = R_V(t)·P_V // C2 IMU 姿态补偿 Cut_V = Q_flower + (0,0,−H) // C3 打顶长度偏移（茎秆直立假设，倒伏跳过） q_cmd = Clamp(Cut_V − P_G0V) // 滑台逆解 + 软限位 通过条件：|FK(q_actual) − q_cmd| ≤ δ_pos // C6 到位校验 延迟处理（C4）：触发式作业无行进运动，采集-推理-执行延迟的影响 由「到位后摆动窗口复检」（C5）消除；行进模式（P1）才启用目标运动预测。

外参标定在某一基准俯角 β₀ 下进行，得 R_res；实际使用时按角度传感器读数实时构造 R_install(β)。因此调节俯角不需要重新标定，但变更后须做单点复核（FR-K1/K3）。

9.2 电气与算力框架

  • 电源：24V 电池一舱（动力：主轴+滑台；电控独立分路：上位机+相机+下位机），各自熔断；急停常闭回路串所有驱动器使能。功耗预算（估算）：主轴 40W（间歇）+ 三轴步进 15W + 上位机/加速器/双相机 15W + 余量 ≈ 平均 70W → 24V×10Ah ≈ 256Wh → 续航约 3.5 h；电池定量化后按 D11 冻结。P0 无行走电机负载；P1 拉车动力另设分路。
  • 算力：主选树莓派 4B（8GB）+ USB 推理加速器；Jetson Orin Nano 为备选升级；冻结依据 = 台架实测「采集→推理→解算」时延 ≤ 300 ms（触发式每株窗口 ≥ 数秒，压力可控）。下位机 STM32F407（168MHz、硬件 FPU、高级定时器×2、ADC 电流采样）。
  • 深度相机安装：可调俯角转台（人工调节，30°–60°），角度传感器读数 β 经 STM32 采样并随遥测上报，进入 R_install(β)；调节俯角后仅需单点复核，无需重标定（6.2）。
  • 软件框架：ROS 2 或轻量自研进程总线 D13 待定；下位机 MCU 实时调度。
  • 接口约定：感知→规划 JSON {cls, conf, x, y, z, t}；规划→STM32 运动指令（目标位/速度/超时）；STM32→上位机遥测（轴位、电流、β、红外键值、急停、电压）。

10 验证与评价

10.1 评价指标口径（引用文献公式；目标初值待 D10 冻结）

漏打率(%) = 漏打株数 / 应打株数 × 100 准确率(%) = (打顶数 − 未准确打顶数) / 打顶数 × 100 // 「准确」= 切点偏差 ≤ δ_pos 上部叶损伤率(%) = 上部叶损伤株数 / 打顶株数 × 100 打顶效果(%) = (1−漏打率)×0.4 + 准确率×0.4 + (1−损伤率)×0.2 〔公式来源：doc/适宜机器打顶作业的烟草种类调研.pdf〕
指标P0 目标初值说明
切点位置偏差 δ_pos≤ 15 mm 待评审到位校验与「准确」判定共用阈值；按茎围 8.6–11.5 cm 与 H 公差推算
漏打率 / 准确率 / 上部叶损伤率≤10% / ≥85% / ≤10% 假设田间验收线；「低损伤」为本机相对固定高度机型的核心卖点，验收从严
花期三态检测 mAP50≥ 0.85 目标初值自建数据集验证集口径（10.2）
单株自动流程时长≤ 5 s 推演值曝光→推理→解算→进给→切割→记录；推行对位时间另计
急停响应≤ 0.5 s 假设硬件回路实测（FR-S1）
连续作业时长≥ 3 h 假设D11 电池定量化后确认
斜切面角度偏差≤ 5° 假设相对配置角 θ（D7 冻结后生效）

10.2 两阶段验证方法

  1. 台架阶段（不依赖花期，可先行）：仿真假株（高度可调）+ 3D 打印红球等替代目标作为烟花顶替身，逐项验证：标定残差、δ_pos 实测、可达性与对位提示、切割成功与过流处理、斜面角度、急停与看门狗、单株节拍；同时用替代目标冷启动数据管线。
  2. 田间初验（花期窗口）：平坦试验田 ≥ 100 株 假设；按 10.1 口径人工复核计数；记录风况与光照时段作为结果解释变量。

10.3 数据集方案（自建为主）

  • 公开示例数据集（预训练/背景）：Tobacco Detection Dataset（Roboflow，662 图/1.97 万标注，植株级）、PlantDoc（2,598 图）——用于预训练与负样本；花期类别范式借鉴 TflosYOLO（茶花三态，自建 29 品种 2 年数据，mAP50>0.8）与苹果花蕾/花两类研究。〔检索 2026-10，详见 README §10.1〕
  • 自建烟草花期数据集（主路线）：双相机同步采集（顶部 RGB-D + 侧 RGB），覆盖现蕾→初花→盛花窗口与晴/阴光照；类别 flower / bud / none（预留 over_mature）；LabelImg/X-AnyLabeling 标注，YOLO 格式；规模 P0 每类 ≥300 张、总量 ≥1,500 张 按采集窗口排产；YOLOv8n/11n 云端训练、边缘部署（ONNX/NCNN→加速器）；田间漏检/误检样本每周回流重训。

11.2 关键假设登记

  • 试验田平整、推行路径可达；万向轮 + 刹车满足推行与驻停稳定性。
  • 触发即视为已对位停稳（人工保证）；车体残余姿态扰动由 C2 承担。
  • 作业光照窗为阴天/早晚为佳；强光下深度可用性以台架实测为准（FR-V5 有降级提示）。
  • P0 假设烟株茎秆基本直立；倒伏/明显倾斜株按跳过处理并记录。
  • 风摆由 C5 复检窗口覆盖；大风天停工为规程要求。
  • 红外接收头装把手侧指向操作员，视线不被遮挡；触发距离 ≤ 数米 典型红外接收距离。
  • 替代目标（3D 打印红球等）仅用于台架与数据管线冷启动，不进入田间验收口径。
