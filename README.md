# 烟草智能打顶机器人（Topping Machine）

<br />

***

## 1. 背景与目标

打顶是烤烟关键农艺环节：现蕾后植株转入生殖生长，须摘除花序及顶部一段茎叶（打顶长度 H），使养分集中供给叶片；打顶过晚或漏打显著减产，打顶还须避免损伤上部叶。

- 我国烟田仍以人工打顶为主，效率低、质量不稳定；国外固定高度机型（如 Spapperi JS-120）存在过度打顶与漏打。
- 机械打顶可比人工节省约 67% 劳动(参考棉花打顶机).
- 适宜机械打顶的株型：株高 140–165 cm、茎围 8.6–11.5 cm、花蕾高度（花顶至打顶位置）> 39.8 cm、上部叶长 < 61.8 cm、茎叶夹角 > 29.9°、披垂角 > 39.5°。

**产品目标**：人工推行(后续可加拉车给予动力)、逐株智能打顶机——对株高差异逐株定位打顶（非"一刀切"），切口为固定倾角斜面，上部叶无损，异常安全停机，作业自动记录。

**本版变更**：定位执行机构由 XYZ 悬臂滑台改为 **Delta 并联臂**（3 条主动臂 + 平行四边形从动臂，3-DOF 纯平动）。刀盘倾角由动平台姿态锁死实现，不再依赖滑台刚性；机械、控制、标定、视觉链路均按此重写，见 §5–§9。

## 3. 作业模式与总体流程

人工推车跨垄对位 → 按红外遥控「作业」键 → 机器自动完成感知-定位-切割-复检-记录 → 提示后推往下一株。

```text
┌──────────────────────── 单株自动流程（红外触发后） ────────────────────────┐
│                                                                          │
│  [红外触发] → 双相机采集(顶部RGB-D 连拍6帧 + 侧RGB)                        │
│      │                                                                   │
│      ├─ 判定=花蕾/无目标 → 跳过提示(短蜂鸣×2) → 等待推往下一株             │
│      │                                                                   │
│      └─ 判定=盛花 → 6帧中值 → 实例分割 → 花顶Z + 拓扑茎点                  │
│              → 射线-平面求交 → 一致性校验 → 切点 P_cut(V系)                │
│              → V→G 变换 → Delta 逆解(θ1,θ2,θ3) → 关节约束判定              │
│              → 三关节伺服 → FK 到位校验                                    │
│              → 主轴达速联锁 → 下探斜切(刀盘倾角固定) → 抬刀回位             │
│              → 残桩复检 → 写单株记录 → 成功提示(长蜂鸣×1)                  │
│                                                                          │
│  异常：目标丢失→重试≤2→记漏打；主轴过流→退刀→重试1次→停机报警              │
│        逆解越界/接近奇异→拒绝下探并提示；急停为纯硬件回路                   │
│  安全：硬件急停（任何状态），红外遥控不承担安全功能                         │
└──────────────────────────────────────────────────────────────────────────┘
```

- **无需停车/静止判定**（D2）：触发即认为就位；车体姿态经 IMU 进入补偿链 K2。
- 切割时建议踩下至少两个万向轮刹车（见 6.1），防止斜切反力使车体漂移。Delta 为闭链结构，末端抗侧向反力优于开链悬臂，但车体漂移仍会直接叠加到切点误差上。

**状态机（P0 简化版）**：

| 状态 | 进入 | 退出 | 禁止 |
| --- | --- | --- | --- |
| IDLE 待机 | 上电/完成一株 | 收到红外「作业」键 | 刀盘旋转、关节运动 |
| ACQUIRE 感知 | 红外触发 | 三态判定完成 | — |
| LOCATE 定位 | 判定=盛花 | 切点通过一致性校验 | 未过校验就解算逆解 |
| MOVE 运动 | 逆解+约束判定通过 | 关节到位且 FK 校验通过 | 越界/超摆角/近奇异仍下发 |
| CUT 切割 | 到位校验通过 | 切割完成/过流 | 未达速下探 |
| VERIFY 复检 | 切割完成 | 残桩判读完成 | — |
| LOG 记录 | 复检完成或异常定性 | 记录写入 → IDLE | — |
| LOST 目标丢失 | 校验/复检失败 | 重试≤2次后记漏打 → IDLE | 盲切 |
| FAULT 故障 | 主轴过流/关节超差 | 退刀重试1次→仍失则停机报警 | 带故障作业 |
| E_STOP 急停 | 硬件触发（任意状态） | 人工复位+重新上电自检 | — |

上电后执行**一次性自检**（关节零位、外参残差、工作空间边界复核、急停回路、电量、存储），通过后每株触发直接进入 ACQUIRE。

## 4. 系统架构

```text
┌────────────────────────── 上位机：树莓派 4B（Linux） ──────────────────────────┐
│  perception/   6帧中值 · YOLO11n-seg 五类分割 · 花顶Z · 拓扑茎点 · 切点解算       │
│  planning/     V→G 变换 · Delta 逆解/正解 · 约束判定 · 状态机                     │
│  control/      关节角指令下发 · 批次/单株记录                                    │
│  hmi/          状态提示(蜂鸣/LED驱动) · 红外触发响应 · 数据导出                   │
└───────┬UART 115200（帧协议+CRC16）──────────────┬USB3────────────────────────┘
        │                                        │
┌───────▼────────── 下位机：STM32F407 ─────────┐ ┌─▼──────────────────────────┐
│ joint_motion   3 关节步进脉冲/限位/零位       │ │ 顶部深度相机 (D435i, 45°)   │
│ io_safety      主轴ESC·电流采样·急停回路      │ │ 侧面RGB相机 (1080p USB)     │
│                红外NEC解码·蜂鸣/LED·看门狗    │ └─────────────────────────────┘
└───────┬───────────┬──────────────┬─────────┘
        │           │              │
   3×主动臂闭环步进  无刷主轴+刀盘   电池+配电（急停常闭回路串所有驱动器使能）
   (带行星减速)     (电流反馈)     24V LiFePO4 → DC-DC 12V/5V
```

**职责划分**：上位机负责非实时的感知、**运动学与约束判定**、状态机与记录；STM32 只负责实时脉冲发生、关节限位、主轴调速与电流采样、红外解码、硬件安全；**急停为纯硬件回路**，不经过任何软件。逆解统一在上位机算，下位机不解算笛卡尔目标，避免两处各一套算法。

**通信协议**（UART 115200 8N1，RS485 为升级备选）：

```text
帧格式: [0xAA 0x55 | CMD | LEN | PAYLOAD | CRC16-CCITT]

CMD  0x01 HOME_ALL         三关节回零(带超时)
     0x02 MOVE_JOINT       目标关节角(θ1,θ2,θ3)+速度+超时
     0x03 SPINDLE_ON/OFF   转速设定/停转
     0x04 GET_STATUS       查询
     0x05 ABORT            退刀停轴(软件中止)
     0x06 SET_TOOL_OFFSET  刀尖偏移写入
     0x07 SET_JOINT_LIMIT  关节软限位写入
遥测(20–50Hz): 关节角×3 · 关节电流 · 主轴电流/转速 · 红外键值 · 急停状态 · 电池电压 · 限位状态
```

| 臂端关节 | 平台端 | Z 行程 | 最大半径 |
| --- | --- | --- | --- |

## 6. 机械设计

### 6.1 车架与行走

- 门式跨垄车架（方钢骨架），**165cm高度**，内宽按实测垄距 + 200 mm 余量。
- 4 × 万向轮，轮径 ≥ 150 mm；**至少 2 轮带刹车锁定**——切割反力会使无锁万向轮漂移，切割前踩刹。
- 后侧推行把手，集成：急停按钮、红外接收头、状态 LED（操作位人因布局）。
- 整机重量目标 ≤ 60 kg（双人可抬运）\[待核定]；电池与电控舱置于车架中部低重心，防护等级 IP54 \[假设待评审]。

### 6.2 Delta 本体

- **静平台**：装于门架横梁下方，三个固定铰点沿 R=139 mm 分布（方位角 0°/120°/240°），安装面水平度 ≤0.5°。
- **主动臂 ×3**：L=140 mm，绕各自切向轴转动，行程 θ ∈ [−90°, +60°]；机械硬限位、驱动软限位、运动学软限位三层同源换算，留 2°–3° 余量。
- **从动臂 ×6**：平行四边形结构，每腿 2 根 l=200 mm；**臂端十字万向节 + 平台端球头铰链**（共 12 个关节）。万向节第一销轴**必须沿切向 t_i**，否则面内/面外摆角分解失效、约束算错。
- **动平台**：r=39 mm，姿态由平行四边形锁死，只有 3 个平动自由度，无绕竖直轴转动；刀盘座直接固定在动平台中心。
- **球窝安装角**：臂端按"主动臂下垂"位姿取 δ₀=30°（=arcsin((R−r)/l)），使锥角围绕行程中段展开；平台端按安装面 135° 取 45° 外倾。平台端若取 0°（竖直），行程损失约 36%。
- **背隙控制**：万向节与球铰背隙 ≤0.3°，按 l=200 折算末端 1–3.5 mm；选可调预紧型，装配后逐关节复测。
- 静平台安装高度、以及 ±120 mm 横向余量能否覆盖人工对位偏差，见 **D15**（未关闭，直接决定整机能否不下移粗调级）。

### 6.3 刀盘组件（倾角固定）

- 刀盘直径 80–100 mm，双刃，刀片快拆。
- **刀盘平面与水平面夹角固定**（建议 30°，D7 农艺确认后由刀盘座加工保证）。Delta 动平台无转动自由度，倾角在全工作空间内恒定——这是改并联构型后"斜切角机械保证"的实现方式。
- 主轴无刷电机直驱；护罩联动——非切割状态刀具完全遮蔽。
- 抑芽/消毒/收集：P0 仅预留安装孔位与供电分路（D5）。

### 6.4 标定工装

- AprilTag 标定板（铝板 + 3 个不同 ID tag），可拆装固定于**动平台**，板在 G 系位置由 FK 已知（见 §9）。
- Delta 自身可提供多组位姿，标定不再依赖外部滑台行程。

## 7. 控制设计

### 7.1 上位机（树莓派）

| 模块 | 职责 |
| --- | --- |
| perception/ | 6 帧中值；YOLO11n-seg 五类分割；花顶 Z（95 分位）；拓扑茎点；射线-平面求交得 `P_cut`；一致性校验 |
| planning/ | V→G 变换；Delta 逆解/正解（闭式）；C1–C5 约束判定；选支；状态机（§3） |
| control/ | 关节角指令下发；批次/单株记录（CSV + 图像编号）；配置与标定档案读写 |
| hmi/ | 蜂鸣/LED 提示语义；红外触发响应；数据导出 |

### 7.2 下位机（STM32）

- 三关节脉冲发生（加减速曲线在 MCU 内生成，上位机只发目标关节角）；零位开关/限位。
- 电机角换算 θ_m,i = i_g·θ_i；驱动器软限位、机械硬限位、运动学软限位三层同源。
- 主轴 ESC 控制 + 电流采样 ADC（过流/空切窗口判断上报）。
- 红外 NEC 解码并上报键值；蜂鸣/LED 驱动。
- 急停回路监视（常闭，断开即切断所有驱动器使能并抬刀回位）。
- 硬件看门狗：与上位机心跳丢失 > 200 ms → 自动抬刀停轴 \[假设初值]。

### 7.3 关节指令生成（约束版逆解流程）

```text
输入：目标切点 P_G，上一周期关节角 θ_prev

1. 逐腿逆解求两支 θ±（圆-圆求交闭式解）
   └─ |d_i/ρ_i| > 1 → 拒绝：几何不可达
2. 按连续性选支（|wrap(θ± − θ_prev)| 取小）
   └─ 两支间距 > 阈值 → 拒绝：接近奇异，轨迹不连续
3. C1 关节行程：θ_i ∈ [−90°, +60°]
4. C2 臂端万向节：面内 α_i ≤160°、面外 β_i ≤90°
5. C3 平台端球铰：锥角 ≤40°
6. C5 奇异裕度：|d_i/ρ_i| ≤ 0.90
7. C4 干涉：6 根从动杆两两距离 > 15 mm
8. 全部通过 → 输出 θ_i 与电机指令；否则给出原因码（哪条腿、哪项约束、超多少）
```

拒绝时必须上报**具体原因码**，现场才能区分"目标给错"与"机械不够"。

### 7.4 补偿链（K1–K6，唯一口径）

> 编号由原 C1–C6 改为 K 系列，避免与关节约束 C1–C5（§7.3）重名。

| 编号 | 补偿项 | 规则 |
| --- | --- | --- |
| K1 | 外参标定补偿 | T_CV 由标定 SOP 获得（§9），首株作业前自检残差 ≤ σ_cal |
| K2 | 车体姿态补偿 | 顶部相机内置 IMU 输出 R_V(t) 进入解算；坡度超阈值提示操作员垫平/换位 |
| K3 | 打顶长度 H 偏移 | 切点高度 = 花顶 Z − H；茎轴倾角 >10° 或裸茎不足的株跳过并记录 |
| K4 | 延迟补偿 | 触发式作业无行进运动，延迟影响由「到位后复检」消除 |
| K5 | 摆动复检 | 切割前复检目标漂移 > 10 mm 则等待并重新定位；窗口超时按 LOST 处理 |
| K6 | 到位校验 | FK(θ_actual) 与 P_cmd 差 ≤ δ_pos(15 mm 初值) 才允许切割 |

## 8. 坐标系定义与转换链

**定义**：

| 坐标系 | 符号 | 原点与轴向 |
| --- | --- | --- |
| 深度相机系 | C | 相机光心；OpenCV 惯例（Z 光轴朝前，X 右，Y 下） |
| 侧 RGB 相机系 | S | 仅用于花期观察与数据集，**不进入切割解算链** |
| 车架系 | V | 门架顶部基准孔；X_V 沿推行方向，Y_V 横向，Z_V 竖直向上（由 IMU/水平调平定义） |
| Delta 基座系 | G | 静平台中心；Z_G 沿静平台法向向上，X_G 与 X_V 平行；原点由制造基准与回零确定 |
| 刀尖系 | T | 刀盘几何中心下刀点；相对 G 的偏移由刀尖标定获得 |

**转换链（每帧解算）**：

```text
1) 像素/点云 → 相机系:      P_C = K⁻¹·[u,v]·depth        （相机内参，出厂/标定）
2) 相机系 → 车架系:          P_V = R_CV·P_C + t_CV         （外参标定，K1）
                             （含安装俯角 β=45°：R_CV = R_install(β)·R_calib残差）
3) 姿态补偿:                 Q_V = R_V(t)·P_V              （IMU 实时姿态，K2）
4) 切点解算:                 Z_cut = Z_top − H；茎点像素射线与水平面求交 → P_cut
5) 车架系 → 基座系:          P_G = R_GV·(P_cut − t_GV)     （机械安装基准 + 标定）
6) Delta 逆解:               θ_cmd = IK(P_G)               （逐腿闭式解，D13 连续性选支）
                             → C1–C5 约束判定，越界拒绝并给原因码
7) 到位校验:                 |FK(θ_actual) − P_G| ≤ δ_pos （K6）
```

**参数速查**：R=139、r=39、L=140、l=200（mm）· θ ∈ [−90°, +60°] · 臂端万向节 160°/90° · 平台球铰 40° · δ₀=30°、δ_s=45° · H（打顶长度，配置）· δ_pos=15 mm、σ_cal=5 mm（初值，待冻结）。

## 9. 标定方案（SOP）

| 步骤 | 内容 | 工具/方法 | 通过判据 |
| --- | --- | --- | --- |
| ① 内参标定 | 深度相机 RGB/深度对齐与内参 | RealSense 出厂 + 棋盘格复核 | 重投影误差 ≤ 0.5 px \[初值] |
| ② 关节零位 | 以主动臂水平（或下垂）机械基准 + 编码器 index 建立零位；零位偏移写入配置 | STM32 HOME_ALL | 重复回零偏差 ≤ 0.1°（末端折算 ≤0.4 mm） |
| ③ 外参 T_CG | AprilTag 板装于动平台（板在 G 系位置由 FK 已知）；Delta 走 ≥3 个位姿，每位姿拍照 PnP 解 T_CG(i)；平均 + 残差 | OpenCV solvePnP | 残差 ≤ 5 mm；超差重标 |
| ④ 外参 T_CV | T_CV = T_CG(i)·T_GV，T_GV 由静平台安装基准（CAD/实测）给出；多姿态残差取优 | 矩阵合成 | 三种位姿残差一致，σ_cal ≤ 5 mm |
| ⑤ 刀尖偏移 | 动平台走已知高度仿形块，刀尖触碰读取终点 → 刀尖相对 G 的偏移写入；换刀后必须重做 | 试切验证块 | 偏移写入成功且复验 ≤ 2 mm |
| ⑥ 侧相机粗标定 | 内参 + 粗外参（仅观察用） | 棋盘格 | 目视对齐即可 |
| ⑦ 开机自检 | 首株触发前：关节回零 + 2 个标准位姿复核外参残差 + IMU 零偏 + 工作空间边界点 + 急停 + 电量 + 存储 | 自动 | 全部通过才放行作业；失败显示原因 |

备选简化外参法（台架阶段可用）：标定板固定于车架已知位置，直接手工量基准尺寸解 T_CV——不依赖 Delta 运动，但精度依赖手工测量，仅作交叉校验。

## 10. 视觉与花期数据集方案

### 10.1 感知链路（当前方案：45° 斜视 + 拓扑茎点）

单株输入 → 切点输出。XY 由茎点决定，Z 由花顶深度决定，两者不互相代入。

| 步 | 动作 | 产出 |
| --- | --- | --- |
| S0 | 连拍 6 帧，丢前 2 帧，逐像素取中值 | 稳定 RGB + 深度 |
| S1 | YOLO11n-seg 实例分割，5 类：`flower_open`/`flower_bud`/`peduncle`/`leaf`/`vein` | 每目标 mask |
| S2 | 花冠 mask + 深度，取 Z_V 95 分位 | 花顶 `P_top` |
| S3 | 叶脉骨架拓扑推断茎点像素 | `S_2D=(u_s,v_s)` |
| S4 | `Z_cut=Z_top−H`，茎点射线与该高度水平面求交 | 切点 `P_cut` |
| S5 | 四项一致性校验 | pass / skip |
| S6 | 输出 Target，驱动 Delta | — |
| S7 | 切割后复检残桩顶面 | 切中 / 切偏 |

**一致性校验**：茎轴倾角 ≤10°、裸茎长度 ≥ H+30 mm、拓扑茎点与花序柄下端 2D 偏差 ≤25 px、花头深度有效率 ≥60%；连续 3 帧 `P_cut` 互差 ≤10 mm，超限重拍一次。

**复检判据**：花冠从视野消失；残桩顶面中心 XY 偏差 ≤10 mm、Z 偏差 ≤10 mm；顶面法向与 Z_V 夹角 ≤15°。任一不满足记为「未切中茎」或「切偏」，不进重试，直接上报。

> 茎点落在可见侧面，沿射线偏出约半个茎径（≈8 mm），在刀盘冗余内不补偿。

### 10.3 自建数据集路线（主路线）

- **采集**：双相机同步（顶部 RGB-D + 侧 RGB），覆盖现蕾期→初花期→盛花期，含晴天/阴天、45° 斜视工位与不同株高。
- **类别**：分割 5 类（`flower_open`/`flower_bud`/`peduncle`/`leaf`/`vein`），三态判定由类别组合给出（open→作业，bud→跳过，none→跳过），预留 `over_mature`。
- **标注**：X-AnyLabeling / LabelMe，YOLO-seg 格式；存入 `dataset/raw` 与 `dataset/annotated`。
- **规模目标**：P0 总量 ≥ 1,500 张，其中 `flower_open` ≥ 400、`flower_bud` ≥ 300、`vein` ≥ 400 \[假设，按 6 周采集窗口排产]。
- **训练**：YOLO11n-seg 微调，云端训练、边缘部署（ONNX/NCNN → USB 加速器）；mask mAP50 ≥ 0.80 \[目标初值]。
- **迭代**：田间漏检/误检样本回流，每周重训一次。

## 11. 电气与安全

- 供电：24V 电池 → 分路熔断（动力 / 电控 / 相机三路）；急停常闭回路串 3 个关节驱动器 + 主轴电调使能。
- 安全项（P0 强制）：硬件急停双按钮、刀盘联动护罩、上电默认安全态（刀具遮蔽、主轴禁转、关节保持）、蜂鸣异音提示语义、作业半径规程（非操作员 ±1 m 禁入）。
- 维护规程：换刀周期、关节润滑与背隙复测、镜头清洁、紧固件检查、消毒间隔（人工）。

## 12. 验证方法与指标

**两阶段**：

1. **台架**（仿真茎秆假株，高度可调）：关节零位重复性、末端重复定位精度（百分表/激光）、背隙折算、工作空间边界复核（指令点 vs 实测点）、切割成功率与过流处理、斜面角度偏差、急停响应、单株节拍。
2. **田间初验**（平坦试验田 ≥ 100 株）：按下方口径人工复核计数，记录风况与光照时段。

**指标口径**（公式源自 `doc/适宜机器打顶作业的烟草种类调研.pdf`）：

```text
漏打率(%) = 漏打株数 / 应打株数 × 100
准确率(%) = (打顶数 − 未准确打顶数) / 打顶数 × 100        「准确」= 切点偏差 ≤ δ_pos
上部叶损伤率(%) = 上部叶损伤株数 / 打顶株数 × 100
打顶效果(%) = (1−漏打率)×0.4 + 准确率×0.4 + (1−损伤率)×0.2
```
