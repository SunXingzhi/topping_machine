# 烟草智能打顶机器人（Topping Machine）

<br />

***

## 1. 背景与目标

打顶是烤烟关键农艺环节：现蕾后植株转入生殖生长，须摘除花序及顶部一段茎叶（打顶长度 H），使养分集中供给叶片；打顶过晚或漏打显著减产，打顶还须避免损伤上部叶。

- 我国烟田仍以人工打顶为主，效率低、质量不稳定；国外固定高度机型（如 Spapperi JS-120）存在过度打顶与漏打。
- 机械打顶可比人工节省约 67% 劳动(参考棉花打顶机).
- 适宜机械打顶的株型：株高 140–165 cm、茎围 8.6–11.5 cm、花蕾高度（花顶至打顶位置）> 39.8 cm、上部叶长 < 61.8 cm、茎叶夹角 > 29.9°、披垂角 > 39.5°。

**产品目标**：人工推行(后续可加拉车给予动力)、逐株智能打顶机——对株高差异逐株定位打顶（非"一刀切"），切口为固定倾角斜面，上部叶无损，异常安全停机，作业自动记录。

## 2. 评审决策状态（原 D1–D10）

切割电机使用无刷电机(之前定量化的),&#x20;

控制位置使用步进电机.&#x20;

保留抑芽机构接口+供电.

相机侧面放一个普通的, 顶部按照**一定俯角**安装深度相机, 选型为会议中提到的

打顶长度(执行机构行程) 根据目标烟种确定--农艺确认（参照花蕾高度适宜值 > 39.8 cm），作为可配置参数

斜切面角度固定.

# 3. 作业模式与总体流程

人工推车跨垄对位 → 按红外遥控「作业」键 → 机器自动完成感知-定位-切割-记录 → 提示后推往下一株。

```text
┌──────────────────────── 单株自动流程（红外触发后） ────────────────────────┐
│                                                                          │
│  [红外触发] → 双相机采集(顶部深度RGB-D + 侧面RGB)                          │
│      │                                                                   │
│      ├─ 检测=花蕾/无目标 → 跳过提示(短蜂鸣×2) → 等待推往下一株             │
│      │                                                                   │
│      └─ 检测=烟花 → 深度定位 → 坐标链解算(C1–C6补偿)                       │
│              → XYZ滑台进给 → 到位校验 → 摆动复检                           │
│              → 主轴达速联锁 → 下探斜切(固定倾角θ) → 抬刀回位                │
│              → 写单株记录 → 成功提示(长蜂鸣×1)                            │
│                                                                          │
│  异常：目标丢失→重试≤2→记漏打；主轴过流→退刀→重试1次→停机报警              │
│  安全：硬件急停（任何状态），红外遥控不承担安全功能                         │
└──────────────────────────────────────────────────────────────────────────┘
```

- **无需停车/静止判定**（D2）：触发即认为就位；车体姿态仍经 IMU 进入补偿链 C2。
- 切割时建议踩下至少两个万向轮刹车（见 6.1），防止斜切进给反力使车体漂移。

**状态机（P0 简化版）**：

| 状态         | 进入         | 退出               | 禁止        |
| ---------- | ---------- | ---------------- | --------- |
| IDLE 待机    | 上电/完成一株    | 收到红外「作业」键        | 刀盘旋转、滑台运动 |
| ACQUIRE 感知 | 红外触发       | 三态判定完成           | —         |
| LOCATE 定位  | 判定=烟花      | 进给到位+复检通过        | 复检失败超限后切割 |
| CUT 切割     | 到位校验通过     | 切割完成/过流          | 未达速下探     |
| LOG 记录     | 切割完成或异常定性  | 记录写入 → IDLE      | —         |
| LOST 目标丢失  | 复检失败       | 重试≤2次后记漏打 → IDLE | 盲切        |
| FAULT 切割故障 | 主轴过流       | 退刀重试1次→仍失则停机报警   | 带故障作业     |
| E\_STOP 急停 | 硬件触发（任意状态） | 人工复位+重新上电自检      | —         |

上电后执行**一次性自检**（外参残差、滑台行程、急停回路、电量、存储），通过后每株触发直接进入 ACQUIRE。

## 4. 系统架构

```text
┌────────────────────────── 上位机：树莓派 4B（Linux） ──────────────────────────┐
│  perception/   YOLO花期三态检测 · 深度点云提取 · (不做全株建模)                  │
│  planning/     坐标链解算 · 补偿链C1–C6 · 状态机                                │
│  control/      运动指令下发 · 批次/单株记录                                      │
│  hmi/          状态提示(蜂鸣/LED驱动) · 红外触发响应 · 数据导出                   │
└───────┬UART 115200（帧协议+CRC16）──────────────┬USB3────────────────────────┘
        │                                        │
┌───────▼────────── 下位机：STM32 ──────────┐  ┌─▼──────────────────────────┐
│ motion_control  三轴步进脉冲/限位/回零      │  │ 顶部深度相机 (D435i, 带俯角) │
│ io_safety       主轴ESC·电流采样·急停回路    │  │ 侧面RGB相机 (1080p USB)      │
│                 红外NEC解码·蜂鸣/LED        │  └─────────────────────────────┘
└───────┬───────────┬──────────────┬─────────┘
        │           │              │
   XYZ闭环步进    无刷主轴+刀盘   电池+配电（急停常闭回路串所有驱动器使能）
   (X/Y/Z)       (电流反馈)      24V LiFePO4 → DC-DC 12V/5V
```

**职责划分**：上位机负责非实时的感知、解算、状态机与记录；STM32 负责实时脉冲发生、主轴调速与电流采样、红外解码、硬件安全；**急停为纯硬件回路**，不经过任何软件。

**通信协议**（UART 115200 8N1，RS485 为升级备选）：

```text
帧格式: [0xAA 0x55 | CMD | LEN | PAYLOAD | CRC16-CCITT]

CMD  0x01 HOME_ALL         回零(带超时)
     0x02 MOVE_ABS         目标位(x,y,z)+速度+超时
     0x03 SPINDLE_ON/OFF   转速设定/停转
     0x04 GET_STATUS       查询
     0x05 ABORT            退刀停轴(软件中止)
     0x06 SET_TOOL_OFFSET  刀尖偏移写入
遥测(20–50Hz): 轴位置×3 · 主轴电流/转速 · 红外键值 · 急停状态 · 电池电压 · 限位状态
```

## 6. 机械设计

### 6.1 车架与行走

- 门式跨垄车架（方钢骨架），**165cm高度**，内宽按实测垄距 + 200 mm 余量。
- 4 × 万向轮，轮径 ≥ 150 mm；**至少 2 轮带刹车锁定**——切割进给反力会使无锁万向轮漂移，切割前踩刹。
- 后侧推行把手，集成：急停按钮、红外接收头、状态 LED（操作位人因布局）。
- 整机重量目标 ≤ 60 kg（双人可抬运）\[待核定]；电池与电控舱置于车架中部低重心，防护等级 IP54 \[假设待评审]。

### 6.2 XYZ 悬臂滑台

- 悬臂梁结构装于门架顶部横梁；X 沿推行方向、Y 横向、Z 升降。
- 三轴原点开关 + 编码器回零；软限位硬约束；防尘罩壳。
- 承载：刀盘组件 + 主轴 ≈ 2 kg 级；悬臂刚度按切割反力校核（机械组计算书输出）。

### 6.3 刀盘组件（倾角固定）

- 刀盘直径 80–100 mm，双刃，刀片快拆。
- **刀盘平面与水平面夹角 θ 固定**（建议 30°，D7 农艺确认后加工保证）；更换刀片不变角。
- 主轴无刷电机直驱；护罩联动——非切割状态刀具完全遮蔽。
- 抑芽/消毒/收集：P0 仅预留安装孔位与供电分路（D4）。

### 6.4 标定工装

- AprilTag 标定板（铝板 + 3 个不同 ID tag），可拆装固定于滑台动平台（位置在滑台系已知，见 §9）。

## 7. 控制设计

### 7.1 上位机（树莓派）

| 模块          | 职责                                                             |
| ----------- | -------------------------------------------------------------- |
| perception/ | YOLO 三态检测（烟花/花蕾/无目标）；检测框内点云中位深度提取；输出 `{cls, conf, x, y, z, t}` |
| planning/   | 坐标链解算（§8）；补偿链 C1–C6；状态机（§3）                                    |
| control/    | 运动指令下发；批次/单株记录（CSV + 图像编号）；配置与标定档案读写                           |
| hmi/        | 蜂鸣/LED 提示语义；红外触发响应；数据导出                                        |

### 7.2 下位机（STM32）

- 三轴脉冲发生（加减速曲线在 MCU 内生成，上位机只发目标位）；限位/回零。
- 控制深度相机位置/获取当前深度相机俯角, 进行坐标系换算.
- 主轴 ESC 控制 + 电流采样 ADC（过流/空切窗口判断上报）。
- 红外 NEC 解码并上报键值；蜂鸣/LED 驱动。
- 急停回路监视（常闭，断开即切断所有驱动器使能并缩回 Z 轴）。
- 硬件看门狗：与上位机心跳丢失 > 200 ms → 自动退刀停轴 \[假设初值]。

### 7.3 补偿链（C1–C6，唯一口径）

| 编号 | 补偿项       | 规则                                         |
| -- | --------- | ------------------------------------------ |
| C1 | 外参标定补偿    | T\_CV 由标定 SOP 获得（§9），首株作业前自检残差 ≤ σ\_cal    |
| C2 | 车体姿态补偿    | 顶部相机内置 IMU 输出 R\_V(t) 进入解算；坡度超阈值提示操作员垫平/换位 |
| C3 | 打顶长度 H 偏移 | 切点 = 花顶沿茎秆向下 H；P0 假设茎秆直立，倒伏株跳过并记录          |
| C4 | 延迟补偿      | 触发式作业无行进运动，延迟影响由「到位后复检」消除                  |
| C5 | 摆动复检      | 切割前复检目标漂移 > 10 mm 则等待并重新进给；窗口超时按 LOST 处理   |
| C6 | 到位校验      | 编码器实际位与指令位差 ≤ δ\_pos(15 mm 初值) 才允许切割       |

## 8. 坐标系定义与转换链

**定义**：

| 坐标系       | 符号 | 原点与轴向                                                    |
| --------- | -- | -------------------------------------------------------- |
| 深度相机系     | C  | 相机光心；OpenCV 惯例（Z 光轴朝前，X 右，Y 下）                           |
| 侧 RGB 相机系 | S  | 仅用于花期观察与数据集，**不进入切割解算链**                                 |
| 车架系       | V  | 门架顶部横梁上的标定基准孔；X\_V 沿推行方向，Y\_V 横向，Z\_V 竖直向上（由 IMU/水平调平定义） |
| 滑台系       | G  | 三轴回零后的编码器零位；轴向与 V 平行（制造公差内）                              |
| 刀尖系       | T  | 刀盘几何中心下刀点；相对 G 的偏移由刀尖标定获得                                |

**转换链（每帧解算）**：

```text
1) 像素/点云 → 相机系:      P_C = K⁻¹·[u,v]·depth        （相机内参，出厂/标定）
2) 相机系 → 车架系:          P_V = R_CV·P_C + t_CV         （外参标定，C1）
                             （含安装俯角 β：R_CV = R_install(β)·R_calib残差）
3) 姿态补偿:                 Q_V = R_V(t)·P_V              （IMU 实时姿态，C2）
4) 切点解算:                 Cut_V = Q_flower + (0, 0, −H) （茎秆直立假设，C3）
5) 滑台逆解:                 q_cmd = Cut_V − P_G0V        （G 在 V 中原点，CAD/回零给出）
                             → 软限位钳位 (q_x, q_y, q_z)
6) 到位校验:                 |FK(q_actual) − q_cmd| ≤ δ_pos （C6）
```

**参数速查**：β（俯角，机械安装角）· R\_CV/t\_CV（外参，标定档案）· H（打顶长度，配置）· P\_G0V（滑台零位在 V 的位置，配置）· δ\_pos=15 mm、σ\_cal=5 mm（初值，D10 冻结）。

## 9. 标定方案（SOP）

| 步骤           | 内容                                                                                         | 工具/方法                | 通过判据                    |
| ------------ | ------------------------------------------------------------------------------------------ | -------------------- | ----------------------- |
| ① 内参标定       | 深度相机 RGB/深度对齐与内参                                                                           | RealSense 出厂 + 棋盘格复核 | 重投影误差 ≤ 0.5 px \[初值]    |
| ② 轴回零        | 三轴原点开关 + 编码器回零，零位偏移写入配置                                                                    | STM32 HOME\_ALL      | 重复回零偏差 ≤ 1 mm           |
| ③ 外参标定 T\_CV | AprilTag 板装于滑台动平台（板在 G 系位置已知）；滑台走 ≥3 个位姿，每位姿拍照 PnP 解 T\_CG(i)；T\_CV = T\_CG(i)·T\_GV；平均+残差 | OpenCV solvePnP      | 残差 σ\_cal ≤ 5 mm；超差重新标定 |
| ④ 刀尖偏移       | 滑台 Z 下探触碰已知高度仿形块，读取终点 → 刀尖相对 G 的偏移写入；换刀后必须重做                                               | 试切验证块                | 偏移写入成功且复验 ≤ 2 mm        |
| ⑤ 侧相机粗标定     | 内参 + 粗外参（仅观察用）                                                                             | 棋盘格                  | 目视对齐即可                  |
| ⑥ 开机自检       | 首株触发前：滑台带标定板到 2 个标准位姿复核外参残差 + IMU 零偏 + 行程 + 急停 + 电量 + 存储                                   | 自动                   | 全部通过才放行作业；失败显示原因        |

备选简化外参法（台架阶段可用）：标定板固定于已知高度/位置，直接手工量基准尺寸解 T\_CV——不依赖滑台，但精度依赖手工测量，仅作交叉校验。

### 10.2 自建数据集路线（主路线）

- **采集**：双相机同步（顶部 D435i RGB + 侧 RGB），覆盖现蕾期→初花期→盛花期全窗口，含晴天/阴天、不同俯仰角。
- **类别**：`flower`（烟花，定位+切割目标）/ `bud`（现蕾期，跳过目标）/ `none`（背景），预留 `over_mature`（过熟）。
- **标注**：LabelImg / X-AnyLabeling，YOLO 格式；存入 `dataset/raw` 与 `dataset/annotated`。
- **规模目标**：P0 每类 ≥ 300 张、总量 ≥ 1,500 张 \[假设，按 6 周采集窗口排产]。
- **训练**：YOLOv8n/11n 微调，云端训练、边缘部署（ONNX/NCNN → USB 加速器）；mAP50 ≥ 0.85 \[目标初值]。
- **迭代**：田间漏检/误检样本回流，每周重训一次。

## 11. 电气与安全

- 供电：24V 电池 → 分路熔断（动力 / 电控 / 相机三路）；急停常闭回路串所有驱动器使能。
- 安全项（P0 强制）：硬件急停双按钮、刀盘联动护罩、上电默认安全态（刀具遮蔽、主轴禁转）、蜂鸣异音提示语义、作业半径规程（非操作员 ±1 m 禁入）。
- 维护规程：换刀周期、镜头清洁、紧固件检查、消毒间隔（人工）——随 PRD v0.2 一并发布。

## 12. 验证方法与指标

**两阶段**：

1. **台架**（仿真茎秆假株，高度可调）：标定残差、δ\_pos 实测、切割成功率与过流处理、斜面角度偏差、急停响应、单株节拍。
2. **田间初验**（平坦试验田 ≥ 100 株）：按下方口径人工复核计数，记录风况与光照时段。

**指标口径**（公式源自 `doc/适宜机器打顶作业的烟草种类调研.pdf`）：

```text
漏打率(%) = 漏打株数 / 应打株数 × 100
准确率(%) = (打顶数 − 未准确打顶数) / 打顶数 × 100        「准确」= 切点偏差 ≤ δ_pos
上部叶损伤率(%) = 上部叶损伤株数 / 打顶株数 × 100
打顶效果(%) = (1−漏打率)×0.4 + 准确率×0.4 + (1−损伤率)×0.2
```
